# ポスト新規作成仕様

## 目的

ログイン中の利用者がタイムラインからポストを作成できるようにする。

## 画面構成

投稿フォームをタイムラインのヘッダー直下、ポスト一覧の前に常時表示する。投稿フォームには次の項目を配置する。

| 項目 | 入力形式 | 必須 | 制約・内容 |
| --- | --- | --- | --- |
| タイトル | 1行入力 | はい | 255文字以内 |
| トピック | 選択 | はい | 登録済みカテゴリから1つ選択する。初期状態は「選択してください」とする |
| 本文 | 複数行入力 | はい | 140文字以内 |
| 投稿者 | 表示のみ | - | ログイン中の利用者名を表示する。入力・選択はできない |
| 投稿ボタン | ボタン | - | 入力内容を送信する |

## 画面動作

1. ログイン中の利用者がタイムラインを開くと、ヘッダー直下に投稿フォームを表示する。
2. タイトル・トピック・本文を入力して投稿ボタンを押す。
3. 入力内容を検証し、問題がなければポストを保存する。投稿者はログイン中の利用者に固定する。
4. タイムラインへ戻り、新しいポストを一覧の先頭に表示する。
5. 作成したポストには投稿者本人の名前を表示し、既存の認可に従って本人に編集・削除操作を表示する。

入力エラーがある場合はポストを保存せず、タイムラインに戻る。入力済みの値を保持し、該当項目の近くにエラーを表示する。

## 入力チェック

| 項目 | チェック | エラー時の動作 |
| --- | --- | --- |
| タイトル | 必須、文字列、255文字以内 | 保存せず、項目の近くにエラーを表示する |
| トピック | 必須、登録済みカテゴリであること | 保存せず、項目の近くにエラーを表示する |
| 本文 | 必須、文字列、140文字以内 | 保存せず、項目の近くにエラーを表示する |

## 認証・投稿者

- タイムラインと投稿処理はログイン中の利用者だけが利用できる。
- ログアウト状態でタイムラインまたは投稿処理にアクセスした場合、ログイン画面へリダイレクトする。
- 投稿者IDはリクエスト値を使用せず、認証済み利用者から設定する。送信内容によって他人を投稿者にすることはできない。

## データ・既存機能への影響

- タイトル・トピック・本文と投稿者は、既存の `posts` テーブルの列を使って保存する。
- `posts` テーブルの列や型は変更せず、マイグレーションを追加しない。
- タイムラインの既存一覧・編集・削除を維持する。他人のポストには編集・削除操作を表示せず、直接URLを開いた場合は403とする。
- リプライ機能と、編集画面の文字数制限・残り文字数表示を維持する。

## 受け入れ条件

- [ ] ログインした状態でタイムラインを開くと、ヘッダー直下に投稿フォームが常時表示される。
- [ ] タイトル・トピック・本文を送信すると、タイムラインの先頭にポストが追加される。
- [ ] 本文が空の場合はエラーが表示され、ポストは増えない。
- [ ] 作成したポストには自分の名前が表示され、本人に編集と削除の操作が表示される。
- [ ] ログアウト状態では投稿フォームにたどり着けず、ログイン画面へ移動する。
- [ ] `posts` テーブルの列・型が変わらず、マイグレーションが追加されない。
- [ ] 既存の一覧・編集・削除、リプライ、編集画面の文字数制限・残り文字数表示が維持される。
