# テストのルール

## テストの追加・更新

- 機能の振る舞いを変更した場合は、関連するテストを追加または更新してください。
- 受け入れ条件をテストケースに反映し、条件ごとに結果を確認できるようにしてください。
- 依頼に含まれる既存動作の維持も、必要に応じて回帰テストで確認してください。
- テストは独立して実行できるようにし、既存データや他のテストの実行順に依存させないでください。

## 投稿機能で確認する条件

投稿の作成・編集を変更する場合は、該当する条件を確認してください。

- 未ログイン時に保護された操作へアクセスできない。
- 他人の投稿を編集・削除できない。投稿者はログイン中の利用者に固定される。
- 必須項目、文字数制限、登録済みカテゴリの制約に違反した入力が保存されない。
- 入力エラーが日本語で表示される。
- タイムラインの現在の動作を維持する依頼では、投稿フォームの表示位置と新しい投稿の表示順を保つ。

## 実行

- Docker Desktop を起動し、テストは `./vendor/bin/sail test` で実行してください。
- 失敗した場合は原因を修正して再実行してください。実行できない場合は、理由と未確認範囲を作業報告に記載してください。
